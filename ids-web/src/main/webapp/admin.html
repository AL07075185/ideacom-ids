    Respaldo y restauración
    Descargar respaldo

    Archivo JSON con sitios, departamentos, usuarios, dispositivos, incidencias y configuración. Sirve para tener una copia o para pasar los datos a otra instalación (por ejemplo, de tu PC a AWS).

    Contiene las contraseñas cifradas de los usuarios. Guárdalo en un lugar seguro y no lo subas a GitHub.
    Restaurar respaldo

    Fusiona el respaldo con los datos actuales: lo que ya existe se actualiza y lo nuevo se crea. No borra nada. Los agentes se vuelven a registrar solos y el sistema los reconoce por su MAC.
